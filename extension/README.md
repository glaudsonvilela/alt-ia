# Mini janela do agente Alt-IA

Esta extensão própria abre a mini janela quando você sai da aba da Alt-IA e a fecha ao voltar. Ela só acessa `https://ai.bigbanana.io/` e usa as permissões de abas e janelas para perceber a troca.

No Chrome ou Edge para computador, abra a página de extensões, ative o modo de desenvolvedor e escolha **Carregar sem compactação**, apontando para esta pasta `extension`. Depois, recarregue a Alt-IA. A extensão não é necessária para as demais funções do site.
