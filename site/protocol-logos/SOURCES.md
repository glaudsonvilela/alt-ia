# Marcas dos protocolos

Símbolos SVG simplificados para máscara de cor na seleção de lending. As formas vêm das fontes oficiais; foram removidos os fundos e as cores originais para aplicar a tonalidade da interface.

- Aave: [Aave DAO Brand Kit](https://github.com/aave-dao/aave-brand-kit/blob/main/Logo/Logomark-purple.svg).
- Fluid: [Fluid token info, Instadapp](https://github.com/Instadapp/fluid-token-info/blob/main/fluid-metadata/assets/Logo%2032px_32px.svg).
- Morpho: [Morpho Brand Guidelines](https://brand.morpho.org/), símbolo para tema escuro.
- Kamino: [Kamino CDN](https://cdn.kamino.finance/kamino.svg). A marca é disponibilizada sob [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) conforme os [termos da Kamino](https://kamino.com/terms); esta adaptação do símbolo segue a mesma licença.
