# Mini janela do agente Alt-IA

Esta extensão própria abre a mini janela quando você sai da aba da Alt-IA e a fecha ao voltar. Quando há um vídeo, a mini janela mostra o player. Ela só acessa `https://ai.bigbanana.io/` e usa as permissões de abas e janelas para perceber a troca.

Baixe [o arquivo da extensão](https://ai.bigbanana.io/alt-ia-agent-extension.zip) e extraia a pasta. No Chrome ou Edge para computador, abra a página de extensões, ative o modo de desenvolvedor e escolha **Carregar sem compactação**, apontando para a pasta extraída. Depois, recarregue a Alt-IA. A extensão não é necessária para as demais funções do site.
